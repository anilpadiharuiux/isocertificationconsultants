## Feature Page Requirements

When building new feature pages:
1. Minimum 1,500 words of content
2. Target 1 primary keyword + 3-5 secondary keywords
3. Include JSON-LD structured data
4. Include CTA section linking to `/contact`
5. Add to `page-registry.md` and `internal-linking-map.md`
6. Add to `app/sitemap.ts`
7. Link from at least 3 existing pages
